# When Did

「最後にやった日」からの経過日数を管理する SwiftUI アプリです。

カテゴリごとに管理したい項目を登録し、実施日を履歴として記録できます。前回の実施日から何日経過したか、必要に応じて次の目安日や累計金額を確認できます。

## 対象

- iOS / iPadOS 向け iPhoneアプリ
- Xcode プロジェクト: `when-did.xcodeproj/`
- Swift ソースコード: `when-did/`

## 開発環境

- Swift 5
- SwiftUI（iOS 26.1以降）
- SwiftData（iOS 26.1以降）
- UserNotifications（ローカル通知）
- Xcode 26.2
- 対応OS: iOS / iPadOS 26.1+

## 主な機能

- カテゴリの登録・編集
- 管理対象となる項目の登録
- 実施日の記録
- 経過日数の表示
- 履歴管理
- 目安日の表示
- 目安日のローカル通知（目安日の朝9時にお知らせ。設定時点ですでに当日9時を過ぎている場合、その日の通知は予約しません）

## 無料アカウント（Personal Team）での開発について

本アプリは有料の Apple Developer Program（年額99ドル）には加入せず、無料の Apple ID（Personal Team）の範囲で開発しています。ローカル通知を含む基本機能までは無料の範囲で実装できましたが、以下の制約があります。

- 実機にインストールしたアプリは **7日で起動できなくなる**ため、使い続けるには7日ごとの再ビルドが必要。日常的に使うアプリとしては手間がかかります
- App Store / TestFlight での配布は不可（開発用の実機インストールのみ）
- iCloud（CloudKit）の Capability が追加できないため、デバイス間のデータ同期は実装不可

本当は iOS と macOS の間で iCloud 同期できるアプリを作りたかったのですが、同期機能は有料メンバーシップが前提となるため、個人利用でそこまで費用をかける必要はないと判断し、今回は見送りました。無料の範囲でできるのはここまで、という線引きです。
